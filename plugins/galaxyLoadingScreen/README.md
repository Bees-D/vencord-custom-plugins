# Galaxy Loading Screen

Covers Discord's in-app loading screen with a purple and blue galaxy: nebula gradients, twinkling and drifting stars, occasional shooting stars, and a glowing orb spinner. It fades out as soon as the server list appears.

Settings: "Loading Discord" text, star density, shooting stars, minimum display time, and a 4-second preview button. Animations stop when Windows asks apps to reduce motion.

Discord's small updater window ("Checking for updates") is a separate window that Vencord does not load into, so it keeps Discord's look.
