# Long Friend Nicknames

Right-click any user and choose **Set Nickname (Discord + Local)**. The dialog has two boxes:

- **Discord nickname**: saved to your Discord account and shown on all your devices. It uses Discord's character limit and only works for friends.
- **Local nickname**: any length. It is saved in your Vencord settings and only shown in this client. When set, it replaces the Discord nickname everywhere Discord shows friend nicknames.

The plugin settings list every local nickname so you can remove them. **Wrap long names** (on by default) makes long names wrap onto more lines instead of ending in "...".

Discord checks nickname length on its servers, so names longer than its limit can only be stored locally.
